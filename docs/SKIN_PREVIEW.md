# 皮肤预览绘制恢复

## 5.7.9 依据与差异

`0049A372 → 0049B010 → 0049A9A3 → 0049A6EF` 使用独立的皮肤管理对象，
创建临时、不可见的普通播放器，先绘制父背景，再枚举可见子窗口并发送
`WM_PRINTCLIENT (0x317, PRF_CLIENT)`。它不是当前播放器的截图，也不是把所有素材首帧
直接铺上去。完成后 `00445709` 替换 BMP 色键，预览框居中、HALFTONE 等比缩小，
小皮肤不放大。原程序此处不创建迷你模式预览。

重建版此前虽已独立解包并正确缩放，子控件合成仍缺少：

- `00467B9B` 初始化的程序／版本信息（资源 `0x80`、`0x8299`）、声道提示
  （`0x81B7`）及空状态文本控件的自定义底色。不能替换成正在播放的歌曲和状态。
- 音量、进度的 fill 层、竖向滑块位置和子控件裁剪；音量此前固定放在横向最右端。
- 无迷你布局时 `004710FD → EnableWindow` 对 minimode 按钮的禁用帧。
- `00415D3D → 0041606F` 按 HICON 原始尺寸在 XML 控件区域内居中并裁剪。
  Let's Vista 的图标区域是 16×26，而非 16×16；原来贴左上角会向上偏 5 像素。

特别注意：Ghidra 的 `00467B9B` 伪代码未恢复音量 setter 的寄存器参数。
实际 `00467F8E` 设置上限 100，`00467F91` 设置下限 0；`00467F9B` 的
`push 50h / pop eax` 后调用 `00428DCD`，**初始预览音量是固定 80%**。
既不读当前音量，也不是 100%。进度保持构造初值 0，缓冲填充长度也是 0。
`00428F41` 的一像素内边距和 `MulDiv` 舍入、`00451E07/0045287B` 从滑块中心
确定填充边界，同样适用于预览。

## 实现边界

`RenderSkinPreview` 接收独立皮肤、资源模块及备用图标，合成上述初始状态。
不访问音频、播放列表、计时器或当前主窗口的控件状态；不修改皮肤包和 `.skn.xml`。
保留上一轮的 LED 字形宽度绘制、PNG alpha、BMP 色键和混合素材透明规则。
这里是等价绘制，不声称重新链接或逐字恢复了原版私有 C++ 类的二进制代码。

按既有需求保留 6.1.2 **皮肤扩展**支持：set、mode_* 等控件仍可显示；login、browser
继续隐藏。因此含这些扩展的 TT2012 预览不会为追求 5.7.9 截图一致而删掉扩展按钮。
6.1.2 未作为选项窗口或其他程序行为的参考。

使用的既有 settings probe 还遍历其他选项页，其唯一菜单结构不一致报告是全屏视觉
已有的 4 项／原版 3 项（社区增加了专辑图片），不应把整份报告误称为完全一致。

`skin_png_tests` 增加固定 80% 横向／竖向音量、零进度填充、未缓冲 fill_image2、
滑条裁剪、无 mini 时禁用帧、图标居中、资源文本与空状态底色的像素回归。

与进度条不重叠测试保留。此批量检查是加载／绘制回归，不代表 182 个包均已和原版
