## 2. 同时完成的简化

- `PublishTrackMetadata` 取代文件属性关闭时的三套同步分支；成功提交当时即可更新歌曲信息。
- `ApplyFileInfoProbeToTrack` 统一列表后台读取、普通查找与媒体库的结果解释，保留全部多值标签，以首值作为显示字段。轨号优先采用原接口的 `Tracknumber`，兼容 `Track`。属性同步同时发布数值声道数与位深，避免用默认零值覆盖其它列表。
- `S_FALSE` 的临时归档结果保留未验证时长标记。媒体库在同一隔离读取会话中等待最终 CRC，沿用每曲目 15 秒总预算，等待可取消；超时仍保留临时状态，不能记作已验证。密码缺失仍可重试。
- `CollectTrackSources` 复用现有导入器的 CUE、压缩包、OSZ、快捷方式及目录遍历。后台目录扫描可使用已验证／已保存密码和分卷映射，但不会主动打开密码或分卷弹窗。
- `PlaybackOptionsFromSettings` 统一播放、选项应用、转换与下载的设置快照；各消费者单独管理取消和生命周期。
- `HttpsProvider` 统一 DLL 路径解析、加载和 API 获取。音频流、查询、更新仍分别保留 Range、ICY、响应大小、重定向及完整性策略。
- 有界 JSON 解析器移到 `ttplayer/core/json.h`，CD 查询、插件文件注册表和更新器共用，保留大小、深度、节点与重复键检查。
- 音频设备信息探测移出窗口线程，以可取消隔离进程执行；旧页面、旧选择的结果不发布。失败名称回退也在子进程中完成。
- 抽取全屏菜单的共同状态更新并清理失效状态，减少不同窗口右键菜单之间的分叉。

## 3. 行为边界

### 3.1 标签并发保存

同一登录会话内，等待写锁的写入在获得锁后读取最新文件，再合并本次字段。已打开的属性草稿或已完成的音频增益分析，如果对应物理文件被外部替换，会返回明确的文件版本错误，保留草稿／拒绝写盘。普通音频在分析后即使只有标签变化也会保守拒绝旧增益结果，需要重新读取或重新扫描；不能把“原子替换成功”当作“没有覆盖别人修改”。版本检查采用文件身份、大小和时间戳，不宣称能阻止任意外部程序绕过协调同时写入。

CUE 增益校验采用音频文件身份及选中轨目的 FILE／INDEX／起止位置，不把标题或其它轨目的增益文本当作音频变化。因此同一 CUE 的两个子轨可以先后保存各自结果；修改下一轨 INDEX 会使受影响的边界过期，更换音频主体同样拒绝旧结果。

压缩包继续只读，音乐窗继续不恢复。本次没有改变用户选定的随机播放索引策略。

### 3.2 旧网络源及硬件

原 NetShow 配置接口没有代理用户名／密码设置方法。显式要求这类认证时返回 `E_NOTIMPL`，不会丢弃凭据后偷偷直连。COM provider 的中止依赖其实现，不能保证任意失控第三方 filter 都按时退出。服务端停止服务也不能通过播放器修复恢复。

KS 的模拟 pin／格式测试与真实声卡测试分开记录。没有实际设备通过记录时，不宣称已经验证所有 ASIO／KS 声卡。

### 3.3 本轮未合并的扩展

- 高位深 Winamp DSP 仍按报告建议作为独立扩展：需要 DLL 哈希、模块和格式白名单及真实插件验证。经典兼容路径继续使用原版的 16 位约定；不能因为参数里有 `bps` 就向所有插件传 24／32 位。
- RLL 导入、新旧播放器同目录共用状态属于产品政策，继续保留现有行为，没有自动搬迁或覆盖用户配置。
- 原宿主 CRT 辅助导出不因序号存在就仿造；本轮恢复三个有明确消费者／接口证据的功能导出。
- `BuildLocalLyricCandidates` 和整包 `ExtractTo` 已确认仍有私有测试消费者。本轮保留这些测试辅助入口，没有让生产路径重新依赖它们；生产使用异步歌词搜索和按引用资源解包。迁移这些历史测试再删除接口属于后续清理。

### 4.1 验证边界及复现资料

- 音效对照采用私有模拟 Winamp 插件及原版／重建版 ttpcomm 对象。真实 Ozone／DFX 等插件和实体 ASIO／KS 声卡未纳入本轮运行。
- 原版导出对照在私有原 EXE 进程中直接执行实际函数，主入口保持挂起，未改原二进制或用户配置。旧 ASF／RM 插件的运行依赖与新宿主分开记录：XP 私有测试目录附带它们要求的 32 位 `MSVCR110.dll`，没有安装或更改系统运行库。
- 三系统均确认原 ASF 插件实际调用名称接口 2 次、缓冲区接口 2 次，普通／Lossless 样本分别输出 40,960／90,112 字节 PCM。原 RM 插件调用名称接口 1 次；当前 RM AC3 样本缺少对应解码器，未把 RM 完整解码及缓冲区分支记为通过。原 AddIn 中未找到 Inet 消费者，网络流通过受控 HTTP 服务直接验证，未混为旧插件使用证据。
- 数据回归包括真实 MP3 文件属性保存后的跨列表即时同步；删除操作截获文件清单并取消，不删除用户文件。归档缩减／空包／CUE 减轨测试使用私有输入，压缩包播放功能仍为只读。
- 原报告的复现缺陷与修复后的验收分别留档；媒体库临时结果未确认的问题是本轮回归新发现并修正的缺口，未通过放宽断言解决。
