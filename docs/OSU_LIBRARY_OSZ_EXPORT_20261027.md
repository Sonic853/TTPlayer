# osu! 专用列表导出 OSZ（2026-10-27）

## 已实现

| 歌曲区右键位置 | 菜单 |
| --- | --- |
| 单首歌曲 | 导出osz文件、导出全部歌曲 |
| 多选歌曲 | 导出已选歌曲、导出全部歌曲 |
| 空白区域 | 导出全部歌曲 |

仅在 stable／lazer 专用列表且 DLL 提供导出接口时显示；普通列表和媒体库不增加这些入口。旧 DLL 保留既有功能，新增菜单隐藏。

单选／多选的导出项放在“选项”之前，使用分隔线区分；空白区域菜单保留“导出全部歌曲”。全屏歌词及视觉菜单的“退出全屏”统一放在最后，位于显示器选择等扩展项之后。

导出单位是完整谱面集合，保留各难度 `.osu`、所有音频、背景、音效、视频、故事板及子目录。选中同一集合的多首歌曲只输出一个 OSZ。lazer 使用数据库中的原始相对文件名，输出不会带哈希文件名。

单首选择保存文件，多选及全部选择输出目录；批量重名自动递增编号，不覆盖已有文件。后台导出提供进度和取消，界面继续处理消息。取消当前包清理临时文件，之前完成的包保留。

## 实现边界

宿主新增上下文菜单、导出对话框、后台线程和 DLL 适配；曲目保留枚举根目录 `TTPlayer.Osu.Root`，标签异步刷新继续保留该字段。

所有谱面集合解析、lazer 映射、归档写入、去重和冲突编号在 `ttp_osu.dll` 的独立导出 ABI 1（序号 5）中实现。原来的 1～4 序号兼容。Action 下载及 ExtraAddIn 验证已允许新序号；主程序 ZIP 继续不包含可选 DLL。

OSZ 使用 ZIP／必要时 ZIP64，成员为 Stored 方法，保留名称与内容字节、不转码，不承诺输出 ZIP 与原始下载包字节一致。游戏曲库只读，缺资源时报告失败。
