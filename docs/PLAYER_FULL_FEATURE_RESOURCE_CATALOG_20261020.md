# TTPlayer 5.7.9 全功能审计：菜单与对话框资源目录

日期：2026-10-20。主报告：[全功能对照与改进建议](PLAYER_FULL_FEATURE_COMPARISON_20261020.md)。

本目录直接读取原版 `ttpres.dll` 和当前 Release 的 PE 资源，不以截图或旧文档猜测菜单内容。
原版 EXE 的业务 UI 资源主要在配套 DLL，因此只检查 EXE 的资源树会漏掉绝大多数功能入口。

## 1. 覆盖和计数

- 原版资源共 192 项：25 组 MENU、49 个 DIALOG，以及字符串、图片、内置皮肤等。
- 当前 DLL 共 207 项；原版 192 项的类型／ID／语言和载荷 SHA-256 全部保持相同，新增 15 项。
- 静态菜单包含 267 条非零叶节点路由，涉及 199 个不同 ID。此数包括运行时替换的子菜单引用／占位项，**不是 199 个独立业务功能，也不是已测用例数**。
- 播放列表、预设、皮肤、服务器、设备等运行时条目，以及按键、鼠标、IPC 和后台流程，还需结合主报告；静态资源无法枚举其所有运行状态。
- 相同的资源字节不证明事件处理、绘制和保存结果一致。表内文字也可能被当前程序按功能或语言动态改写。

原版 DLL SHA-256：`866726b4c9b712ef0cb5492a74d05bbb15a97f8f47595d743dcf268aa25853a5`。

当前 DLL SHA-256：`f4db74b1f4095fa1d25146ec33265ec4b3ade12dff9c5e75680c44a3e9138df6`。
