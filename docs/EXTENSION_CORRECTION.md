# 错误文件后缀的确认更正

日期：2026-09-24。

## 设置与行为

在 **选项窗口 → 常规 → 选项** 中新增 **识别到错误后缀时提示更改**，默认启用。

- 启用：仅在歌曲开始播放、解码器成功打开文件后，核对文件的实际容器／帧头，发现错误后缀时提示更改。添加歌曲、扫描媒体库、后台读取歌曲信息时不弹出此提示。
- 关闭：不弹出更名提示、不修改后缀；继续使用现有的实际格式识别和解码回退方式播放。
- 取消：保留原文件和播放状态。同一次运行中，同一路径且大小、修改时间、文件身份未变的文件不重复提示。
- 确认：只改文件名，不转码、不改音频数据。目标名称已存在时，显示源文件和已有文件的完整路径、易读大小及精确字节数，提供 **覆盖／加编号／取消**。
- 加编号：生成 `文件名 (1).扩展名`，已有编号自动跳过；不会覆盖已有文件。
- 覆盖：仅使用对话框中展示过的目标文件。文件身份、大小或修改时间变化时停止操作，提示错误；不会先删除目标文件。

XML 持久化字段为 `General/@PromptExtensionCorrection`；旧配置没有此字段时沿用默认启用。常规页的关闭、全部保存和全部重置沿用已有设置流程。

提示只针对当前成功打开的播放会话。若选项窗口等暂时阻止弹窗，期间已经停止或切换歌曲，旧歌曲的待处理提示会被丢弃；仅存在于播放列表中的歌曲不会因此弹窗。取消后不重复提示的规则不变。

## 与格式恢复的关系

这是重建版新增的交互功能，不是对原版已有改后缀对话框的复刻。此前恢复的原版格式提示、插件候选顺序及系统解码回退逻辑保持独立，见 [格式恢复说明](FORMAT_ROUTING_RECOVERY.md)。新设置不参与解码器选择。

`AudioExtensionHint` 和原版恢复出来的短头部路由提示不直接用于改名。更名候选需要成功的读取结果，再检查实际文件头；未知或证据不足的格式不猜测后缀。损坏文件、无法成功读取的文件不会仅凭伪装的后缀弹出更名建议。

已覆盖的容器／流头包括 WAVE/RF64/BW64、AIFF/AIFC、AU、FLAC、APE、TTA、WavPack、Musepack、Ogg Vorbis/Opus/FLAC、MP4、ASF、RealMedia、MIDI/RIFF MIDI、AMR、ADTS AAC 和 MPEG Audio。MPEG 和 ADTS 要求至少两个连续且一致的完整帧；可跳过合法 ID3v2 标签。

优先采用外层容器：MP4 中的 AAC 不会被更名成裸 `.aac`，ASF 不会仅因音频编码就被当成独立 WMA 流。保留 `.m4a/.mp4`、`.wma/.asf`、`.aif/.aiff`、`.ape/.mac`、`.flac/.fla` 等合法别名，大小写差异不会触发提示。网络 URL、压缩包成员、CUE 子轨以及重解析点不进入物理文件更名流程。

## 文件及播放状态

更名操作前再次核对源文件的身份、大小和修改时间。默认名称和编号名称使用不覆盖的 `MoveFileW`；明确选择覆盖后才使用 `MoveFileExW(MOVEFILE_REPLACE_EXISTING)`。这也保留了 XP／Win7 API 兼容性。

成功后同步更新所有播放列表、媒体库快照、当前播放副本、恢复播放路径与按媒体路径保存的歌词关联。覆盖已有文件时替换其旧媒体信息，保留列表条目的评分。正在播放／暂停的相关文件会先释放读取句柄，再恢复播放位置及暂停状态；文件占用、权限不足等失败会报告系统错误，列表不会提前改成不存在的新路径。

同目录 `.lrc` 文件不随本功能改名；显式歌词关联会迁移到新的媒体路径。本功能不负责更新播放器以外的播放列表、快捷方式或第三方数据库。

## 验证

- 普通版、XP／Win7 版 Release 构建通过。
- Windows 11 上两版均通过 99 项检查：80 个真实格式／后缀组合，以及设置默认值与持久化、只检测不改名、字节保持、同名拒绝、编号跳过、明确覆盖、源／目标变化拒绝、别名和容器优先等。
- XP、Win7 虚拟机分别执行兼容版测试程序，均通过同一组 99 项检查。
- Windows 11 实际界面：确认新复选框位于常规的“选项”页且默认勾选；确认普通更名和编号更名后继续播放；取消保留原文件；关闭设置后错误后缀仍能播放，且退出后保存关闭状态。
- 播放时机调整后的界面回归：通过 `/a` 只添加错误后缀测试文件，后台成功读出 5:00 时长而无提示；双击开始播放后才出现更名确认，取消后继续正常播放。
- 兼容版静态导入检查通过：x86、子系统 5.01、19 个 DLL／655 项导入。

测试源代码和辅助脚本仅位于本地 `rebuild/tests`；没有加入发行 ZIP，也没有新增 Actions 测试步骤。虚拟机检查覆盖底层识别、更名与设置持久化；完整新对话框的人工式界面操作检查在 Windows 11 上完成。
