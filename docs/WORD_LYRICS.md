# 逐字歌词与编辑

普通版和 XP／Win7 版共用逐字歌词实现。支持在 LRC 行内用尖括号标记绝对播放时间：

```text
[00:27.560]<00:27.560>执 <00:27.900>念 <00:28.340>的 <00:28.840>鱼<00:30.000>
```

方括号是行时间，尖括号是后续文字的开始时间。一个标签可以对应一个字或一个词。
最后一个空标签可明确上一段文字的结束时间；未提供时使用下一行时间，最后一行使用原有的
一分钟后备区间。支持一位、两位、三位小数，分别按十分秒、百分秒、毫秒解析。
普通行 LRC 可以与逐字行混用。

## 显示

- 窗口、迷你窗口、全屏和桌面歌词使用同一份逐字时间数据。
- 开启对应显示模式的 **卡拉 OK** 后，高亮按字／词时间及实际字体宽度推进；关闭时仍整行高亮。
  窗口、全屏、桌面沿用各自已有的开关，不修改用户设置。
- 时间标签不出现在播放显示中；行内空格、连续空格和英文单词间空格保留。
  “去除行首和行尾的空格”只裁剪首尾，并同步修正字位置。
- 折行按同一条时间轴高亮，不会提前点亮下一显示行。桌面歌词的长行滚动使用逐字进度。
- 歌词偏移、提前／延后、当前行／后续行调整同时作用于行时间和字时间。

## 编辑

进入 **编辑歌词** 后，原文件的逐字标签显示为时间标签颜色，可以直接编辑文字或时间。
右键菜单在原有行标签命令旁新增：

| 命令 | 快捷键 | 行为 |
| --- | --- | --- |
| 插入逐字标签 | Ctrl+F8 | 在光标处写入当前播放时间；随后移到下一字符，保留空格 |
| 替换逐字标签 | Ctrl+F9 | 更新光标所在或其后第一个有效逐字标签 |
| 删除逐字标签 | Ctrl+F10 | 删除光标所在或其后第一个有效逐字标签，保留歌词文字 |

新建的纯文字行首次插入逐字标签时，也会补齐行时间。插入时考虑文档的 `[offset:]`。
替换已有逐字行的行时间时，同步移动该行字时间，保留相对节奏。
整体调时、压缩、展开、繁简转换、保存及内嵌歌词序列化均保留逐字数据。
压缩时不合并带绝对字时间的重复行，避免不同播放位置共用错误字时间。
直接保存未经改写的编辑文本保留其原有时间精度；重新序列化逐字行使用三位毫秒格式。

## 测试文件中的非标准时间

提供的《夜航星》文件有 `<00:51.68>我<00:51.100>曾` 一类时间倒退。
它主要使用两位百分秒，三位小数仅有 `.100`，符合百分秒达到 100 后未进位的特征。
解析器仅在同时满足这些条件时，将 `.100` 按下一整秒兼容处理；正常的 `.100` 毫秒值
和含其他三位毫秒值的文件不启用此规则。播放和整体调时使用同一检测规则。
该兼容不会直接改写原文件；重新序列化后输出规范时间。

## 验证

本地私有测试位于 `tests/ui/word_lyrics_tests.inc`，由现有原生界面测试调用，覆盖：

- 提供的 LRC 解析与保存回读、普通行混用、空格保留、三位毫秒及异常进位；
- 不等长中英文的 GDI 高亮边界、折行片段、结束标签、偏移与行时间调整；
- 逐字菜单、标签颜色、连续打轴、替换／删除、压缩／展开及保存后重新显示；
- 既有行歌词解析、桌面滚动、全屏透明绘制和歌词菜单回归。

使用提供的 MP3／LRC 副本进行实际播放检查，原始文件不由测试写入。
测试只在本地运行，不加入发行包，Actions 继续关闭测试。
