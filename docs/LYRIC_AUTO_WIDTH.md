# 歌词窗口自动适应宽度（2026-09-21）

> 2026-09-21 补充：相关功能已在 XP SP3 / Win7 SP1 虚拟机中执行回归。覆盖项、修复和未覆盖边界见 [虚拟机验证记录](XP_WIN7_VM_VALIDATION.md)。下文保留原日期的历史结论。

## 原版依据

对照 `reverse/decompiled/TTPlayer.exe.pseudo.c`：

| 位置 | 行为 |
| --- | --- |
| 设置读写，176575–176591 行 | `Lyric/AutoWidth` 对应设置偏移 `+0x3DC`，`AutoWidthOnlyVert` 对应 `+0x3E0`。桌面歌词使用独立的 `DesktopLyric/AutoWidth`。 |
| `00496FE3`、`0049702F` | 复选框 `2022`、`2023` 修改设置后立即发送 `0x7F0/0x10`；关闭自动宽度时禁用“仅垂直滚动时”。 |
| `0044919C` | 用皮肤 `lyric_window/resize_rect` 是否为空决定能否自动调整。固定尺寸皮肤不拉伸。 |
| `00449A8F` | 全屏分支转交自动字体调整；普通／迷你窗口检查自动宽度及垂直滚动限制。 |
| `0043F0C1 → 0043E961` | 使用当前歌词字体，遍历整首歌词，取 `DrawText` 的 `DT_SINGLELINE | DT_CALCRECT | DT_NOPREFIX`（`0xC20`）最大宽度；不使用当前播放行，也不加字体高度补偿。 |
| `0044A0E8`、`0044A26F`、`0044A370`、`0044B4A1` | 清空、载入歌词及修改字体／自动宽度选项后重新计算。 |

计算顺序：

1. 将最大歌词行宽限制到 `SPI_GETWORKAREA` 返回的工作区宽度。
2. 加上当前歌词窗口外宽与 `LyricCtrl` 客户区宽度之差，保留实际皮肤边距。
3. 不小于歌词窗口背景位图的原始宽度。空歌词的目标行宽为零，因此回到皮肤最小宽度；默认提示语不参与测量。
4. 保持窗口高度和顶部位置。通常保持左边缘；窗口位于主窗体左侧、与主窗体右边缘对齐且从左侧伸出，或贴着工作区右边缘时，保持右边缘。
5. 使用 `SetWindowPos(..., 0x34)`，不激活窗口、不改变 Z 顺序。

这里的屏幕上限作用于**歌词文本宽度**，之后才加皮肤边距；与原版一致，极长歌词的最终外宽可以超过工作区宽度几个边框像素。

## 重建版修复

之前只实现了这两个设置的读写和复选框，没有窗口宽度消费者。

- 新增 `PlayerWindow::ApplyAutoLyricWidth`，恢复上述测量、最小宽度和边缘保持规则。
- 接入文件／拖入／下载歌词、嵌入歌词、异步本地搜索、清空歌词、编辑返回、字体和选项变化。
- 普通、迷你、透明且隐藏皮肤的布局均按实际歌词客户区测量边距。
- 创建控件、切换透明皮肤和退出全屏时，先完成布局，再使用新字体计算宽度，避免用旧客户区导致反复变宽。
- 不在绘制、动画计时器或 `WM_SIZE` 中重新适应，手动改变宽度后不会立即被改回。
- 补齐 `2023` 的初始禁用状态和随 `2022` 切换的联动。

按本次要求，`LyricSettings::auto_width` 默认改为 `false`。新配置、缺少该属性的配置和“全部重置”使用关闭状态；已有明确保存的 `AutoWidth="1"` 仍保留用户选择。`AutoWidthOnlyVert` 保持原默认值，关闭主选项时不生效。

全屏继续使用独立的 `AutoFontFS`，桌面歌词继续使用自身的自动宽度算法。
2026-09-23 补充：提供 `content_minimum` 的外部皮肤可使用自身最小尺寸和 `content_state`
实际边距接入自动宽度；Winamp 视频歌词已接入。纯视觉模式跳过自动宽度，旧插件继续保持原行为。

## 验证

本地用真实歌词窗口消息过程、原始对话框 384 和默认皮肤验证：

- 默认关闭、缺省 XML 属性、显式开关保存／恢复；
- 复选框即时生效及从属控件联动；
- 最宽行在后续时间戳时仍正确适应，长短歌词切换、空歌词回到最小宽度；
- 文件、嵌入歌词和异步本地搜索加载，字体变化；
- 左右边缘保持、工作区宽度上限；
- 横向／垂直限制、迷你模式、固定尺寸皮肤、全屏隔离；
- 透明皮肤切换后的边距、重复调用稳定、手动调整不被立即覆盖。

回归代码仅存放于 `rebuild/tests/ui/lyric_auto_width_tests.inc`，由本地 `options_drawing_tests --lyric-auto-width` 运行。Actions 保持 `BUILD_TESTING=OFF`，不分发测试代码。

上述专用回归、`fullscreen_lyric_render_tests` 和 `skin_rebind_tests` 均通过。普通版和 XP／Win7 版 Release 构建成功；兼容版静态导入审计通过（19 个 DLL、651 个导入项，x86 子系统版本 5.01）。本次未在 XP／Win7 虚拟机中运行界面测试。
