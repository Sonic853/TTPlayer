# osu! 设置页、程序识别与星环效果显示条件

## 1. 本次调整

- 选项 → 媒体库的子页顺序为 **媒体库 / osu!lazer / osu!**。
- osu!lazer 页包含程序文件、歌曲目录（files）；osu! 页包含程序文件、歌曲目录（Songs）。保留原 XML 字段和默认路径，已有设置无需迁移。
- 路径标签、输入框、浏览按钮并排；标签固定宽度，输入框伸缩，浏览按钮靠右，重复布局不会累积偏移。
- 浏览按钮使用原资源 **BITMAP 1023** 的文件夹加放大镜图标及已有原生按钮绘制。程序选择器筛选 `*.exe`；目录使用现有文件夹选择器，取消保持原值。继续复用现代 Windows 与 XP 的文件选择兼容实现。
- 输入框统一使用原生 `WS_EX_CLIENTEDGE`。同时调整个性化名称、星环 BPM、自定义开场文字、自定义图案路径输入框；全屏备用图片的浏览与清除按钮采用已有位图按钮样式。
- 稳定版星环的自定义图案浏览按钮与路径并排；lazer 页的浏览按钮放在徽标选择右侧，避免遮挡三段开场文字。

## 2. 可执行文件识别

后续已将检查迁入 `ttp_osu.dll` 的安装信息 ABI 1，宿主通过
`audio::IdentifyOsuExecutable` 调用，不再保留 `src/settings/osu_executable_identity.h`。
该接口只读检查用户配置的程序文件，支持环境变量及带引号路径。迁移细节见
[安装信息迁移](OSU_INSTALLATION_DLL_MIGRATION_20261027.md)。

先确认有效 PE32 / PE32+ 可执行映像、非 DLL、节区与入口点边界及版本资源范围，再交叉检查以下版本字段：

| 字段 | osu! stable | osu!lazer |
| --- | --- | --- |
| ProductName、FileDescription | `osu!` | `osu!(lazer)` |
| OriginalFilename、InternalName | `osu!.exe` | `osu!.dll` |
| CompanyName | `ppy` 或 `ppy Pty Ltd` | `ppy` 或 `ppy Pty Ltd` |

这对应本机提供的实际程序，包括 lazer `current` 下的 x64 apphost 和根目录入口。识别不依赖磁盘文件名：真正的游戏改名后仍能识别；其他程序仅改名为 `osu!.exe` 不会通过。不执行或加载游戏代码，也不要求在 XP 上启动现代 lazer。此检查用于辨认程序特征，不替代数字签名验证；未来上游更改身份字段时需更新识别规则。

## 3. 可用条件与刷新

两条程序路径中 **任意一条** 识别为 stable 或 lazer，就满足游戏安装条件。两种全屏效果还分别要求可选 `ttp_osu.dll` 提供对应的视觉接口：

| 游戏识别 | 插件能力 | 结果 |
| --- | --- | --- |
| 任一有效 | 完整视觉接口 | 显示节拍星环、星环lazer，以及两者的视觉参数标签页 |
| 两者均无效 | 任意 | 隐藏两种效果及对应标签页 |
| 任一有效 | 无插件 | 隐藏相关功能 |
| 任一有效 | 旧版部分接口 | 仅显示实际支持的效果 |

菜单、全屏类型列表和视觉设置标签页使用统一条件。OSZ 解包、歌曲库读取仍按 DLL 自身能力判断，不受游戏 exe 识别结果限制。保留两种星环仅在全屏中显示的既有要求。

识别结果在启动时缓存，路径编辑采用 350 ms 合并刷新，并在浏览成功、失焦、切页、提交及相关页激活时同步刷新。动画帧不读 exe。外部移动程序后重新进入相关设置页，也会重新识别。若当前选中效果变为不可用，切回频谱分析；对应参数保留。

## 4. 验证

### 身份识别

私有测试 `tests/osu_identity_20261027` 的 36 项检查通过：真实 stable / lazer / 根入口、环境变量、引号、改名游戏、普通程序改名、非 PE、截断、非法偏移/节区/入口点、DLL，以及五项版本字段逐项篡改。

### 原生窗口测试

Windows 11、XP 和 Win7 均通过：

- 三个媒体库子页的顺序、显示范围、鼠标和键盘切换、隐藏控件焦点转移。
- 标签/输入框/按钮对齐、原生编辑边框、居中图标、18×14 DLU 按钮、实际加宽及恢复无漂移。
- 仅 stable、仅 lazer、两者有效、两者无效、两种身份放入另一输入框的组合。
- 已创建菜单/全屏列表/视觉标签页动态更新；快速切页刷新；外部移动程序后的再次激活刷新。
- 无效路径使隐藏效果退出选中；窗口模式不暴露两种全屏效果。
- XML、中文路径、环境变量、显式空值、重复初始化及重开。

Windows 11 另外通过常规四页和全屏三页既有回归、无插件隔离目录回归。实际窗口截图保存在私有 `tests/osu_options_20261027`，已检查 XP / Win7 / Windows 11 的布局与图标。文件选择器复用既有实现；本次未自动操作真实文件选择器的确认/取消界面。

Release 构建和 XP / Win7 静态导入检查通过。源码、测试和游戏样本不加入发行包；不修改原版游戏文件或安装配置。测试所启动的虚拟机在结束后恢复关闭状态。

## 5. 主要文件

- `src/ui/options_library_tabs.h`：三页布局和浏览控件。
- `include/ttplayer/audio/osu_installation.h`、`src/audio/osu_plugin_client.cpp`：安装信息接口适配；识别和路径发现实现由 DLL 提供。
- `src/ui/osu_visual_availability.h`：缓存及统一可用条件。
- `src/ui/options_visual_tabs.h`：动态效果页与控件样式。
- `src/ui/player_window_options.cpp`：路径选择、状态提示、刷新与全屏列表。
- `src/ui/player_window_visual.cpp`、`player_window_visual_options.cpp`、`player_window_internal.h`：菜单、参数页及运行时入口。

发布输出位于 `build/Release`。`ttp_osu.dll` 保持可选插件，由其独立包提供。后续安装信息迁移已同时更新播放器和插件，需使用配套版本。
