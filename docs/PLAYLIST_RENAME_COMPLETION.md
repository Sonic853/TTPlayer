# 播放列表重命名：点击空白处后的行为

分析与修复日期：2026-09-27。

## 结论

原版在重命名期间点击左侧列表目录的空白处，会保存非空的新名称并结束编辑。
**第一次点击保留目录选中项、焦点项和当前播放列表；第二次点击才执行普通空白点击，
清除选中项，但保留焦点项与当前播放列表。** 点击右侧歌曲区造成失焦也会提交名称。

重建版之前把 `WM_KILLFOCUS` 一律作为取消，并在编辑框关闭后继续处理同一次目录点击，
因此同时出现“新名称丢失”和“第一下就清除选中项”两处差异。

## 1. 原版伪代码调用链

依据 `../reverse/decompiled/TTPlayer.exe.pseudo.c`：

| 地址/函数 | 作用 |
| --- | --- |
| `00482BAF` | 创建 `PlayLists` 列表控件 `0x2801`，目录名称使用原生列表控件标签编辑 |
| `0048516E` | 重命名命令 `0x7F04`；用 `LVM_GETNEXTITEM(-1, LVNI_SELECTED)` 取得目录项 |
| `0048468A` | 新建目录后激活最后一项，进入同一标签编辑流程 |
| `0044DEF5` | 发送 `LVM_EDITLABELW`（`0x1076`），取得内嵌 Edit 窗口 |
| 播放列表消息分发器，`0047BB8E` 附近 | 将控件 `0x2801` 的 `LVN_ENDLABELEDITW`（`-0xB0`）路由至 `00489B06` |
| `00489B06` | 检查 `LVIF_TEXT`、`pszText != nullptr`、首字符非零；满足条件则赋给对应目录名称 |
| `00489AE2` | 根据目录项选中变化切换当前列表；普通空白点击不应切换活动列表 |

`00489B06` 的关键逻辑为：

```text
if ((item.mask & LVIF_TEXT) && item.pszText && item.pszText[0])
    对 item.iItem 对应的播放列表赋予新名称
```

这里没有“必须按 Enter 才保存”的限制，也没有去除首尾空格的逻辑。
鼠标结束编辑时具体发送哪种通知、是否继续处理该次点击，由原生列表控件负责，
不能只从播放器 EXE 的赋值函数推断。为此补充了对提供的原版程序的实际点击对照。

## 2. 原版运行对照

使用独立副本 `out/test-artifacts/playlist-rename-20260927/original/RenameOriginal.exe`，
LX-iPlay 皮肤及隔离配置，通过实际鼠标和键盘输入检查：

1. 右键目录项 → 重命名，输入 `BlankCommit`。
2. 点击同一左栏的空白处：编辑框消失、名称显示为 `BlankCommit`，选中高亮仍在。
3. 再次点击该空白处：选中高亮消失，目录焦点框保留。
4. 再次重命名为 `TrackBlankCommit`，点击右侧空白歌曲区：新名称保留，焦点进入 `Files`。

先前 `PLAYLIST_MENU_INPUT.md` 将失焦描述为取消，这个结论不成立。
旧 `RenameBlur` 探针从另一个进程调用 `SetFocus`，既没有验证焦点是否转移，也没有
验证编辑框是否结束，随后直接关闭程序并读取文件。这不能证明真实鼠标失焦时的行为。
本次以原版实际输入与窗口状态变化修正该结论。

## 3. 重建版修复

文件：`src/ui/player_window_playlist.cpp`。

- 目录子控件发现仍在编辑时，先转交父窗口处理，避免提前 `SetFocus` 销毁编辑框，
  丢失“本次点击发生于编辑期间”的状态。
- 父窗口接到目录区域的左键按下时先提交编辑并返回，不继续取消选中、切换列表或发起拖动。
  子控件转发与直接发给父窗口的两种路径保持一致。
- `PlaylistEditProc` 将普通 `WM_KILLFOCUS` 改为提交，继续沿用非空检查和 `PlaylistStore::Rename`。
- Enter/Esc 结束后将键盘焦点交回目录；失焦提交时保留新的焦点目标，避免抢回歌曲区焦点。
- Esc、显式关闭列表窗口和销毁窗口仍走取消路径；空名称被拒绝，已有名称保持不变。

| 操作 | 修复后的结果 |
| --- | --- |
| 编辑中第一次点左栏空白 | 提交非空名称，保留选中项及当前列表 |
| 编辑结束后再点左栏空白 | 取消选中，保留焦点项及当前列表 |
| 编辑中点击右侧歌曲区/其他焦点目标 | 提交名称，焦点留在目标控件 |
| Enter | 提交，焦点返回目录 |
| Esc | 取消，焦点返回目录 |
| 空名称后 Enter、点空白或真实失焦 | 结束编辑，保持旧名称 |
| 纯空格或首尾包含空格的名称 | 原样保存 |
| 滚轮到达列表 | 提交非空名称并结束编辑，再处理滚动 |
| 显式关闭或销毁列表窗口 | 取消尚未提交的编辑 |
