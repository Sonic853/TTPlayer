# 主窗口与独立窗口菜单核对（2026-09-23）

依据为 5.7.9 `reverse/decompiled/TTPlayer.exe.pseudo.c` 和对应 `ttpres.dll` 菜单、字符串资源。
本次核对共享菜单的内容、状态与命令入口，不将加载了同一个资源等同于功能已恢复。

## 均衡器问题与原版依据

主窗口菜单资源 `0x8A` 的均衡器项指向 `0x90`。后者的“可选类别”只有：
命令 `0x7E90`、文字 `<>`，以及分隔线、从文件加载、保存到文件。
类别名称不在这个静态菜单中。

- `CPlayerWnd_ShowMainContextMenu`（`0045DFBA`）将资源菜单接入主菜单。
- `CPlayerWnd_OnInitMenuPopup`（`00461BAE`）识别首项 `0x7E90`，调用 `004299CD` 动态填充。
- `004299CD` 保留最后两个加载／保存命令，重建分隔线与 12 个类别。
  名称取字符串资源 `0x8174` 的第 1～12 项，缺失时取 EXE 的英文表。
  命令为 `0x7E91..0x7E9C`；按当前 Profile 设置普通勾选标记。
- `0045Axxx` 的共享 UI 更新负责推荐 `0x7E2D`、自定义 `0x7E2E`、
  启用 `0x7E2C` 和杜比环绕 `0x7DFA` 的状态。
- 均衡器消息分发 `00453D7E` 将推荐配置转成预设 0，处理自定义、启用、环绕、
  预设范围及 `0x7E2F/0x7E30` 加载／保存。

重建版此前仅在 `ShowEqualizerProfileMenu` 内填充类别和四个勾选状态。
主窗口只拼接静态资源；其命令路由也未进入 `HandleEqualizerCommand`。
因此不仅显示 `<>`，主菜单的推荐、自定义、启用、环绕、文件操作也没有正常调用均衡器处理。
这属于程序实现遗漏，与 Windows 主题、WTL 绘制或系统版本无关。

### 修复

1. 提取 `PopulateEqualizerPresetMenu` 与 `PrepareEqualizerMenu`，主菜单和独立均衡器菜单共用。
2. 初始化类别及重新展开时刷新条目和勾选，保持加载／保存尾项且不重复插入。
3. 主窗口 `WM_INITMENUPOPUP` 支持原占位项和已填充列表；动态插入后补上现有自绘记录。
4. 均衡器窗口转发初始化通知，移除其 `TPM_NONOTIFY`，仍通过 `TPM_RETURNCMD` 返回所选命令。
5. 主菜单接入同一个均衡器命令处理。均衡器隐藏／未创建时，文件对话框使用主窗口作为 owner。

按后续要求，两个均衡器右键菜单均增加“重设均衡器”（命令 `0x7E31`），置于“启用均衡器”前。
文字沿用皮肤重设按钮的本地化资源 `0x8176`。这是新增的菜单入口，行为与原有皮肤按钮共用：
前置增益与十段频率归零，并更新自定义配置；已启用时切为自定义，已关闭时保持关闭。
声道平衡、环绕及音量沿用原重设按钮语义。重复准备菜单不会重复添加条目。
该入口扩展已通过宿主机、XP SP3、Win7 SP1 共享菜单回归，覆盖两个菜单和皮肤按钮在启用／关闭状态下的重设。

推荐、类别切换保留前置增益；禁用／启用恢复原 ProfileLast；环绕按 0／8 切换。
沿用已有均衡器音频与配置读写实现。

### 后续补齐及边界

按后续要求，已补齐“重新排列／重置窗口”（`0x7DD6`）的独立命令实现。
普通、迷你、非皮肤及桌面歌词布局依据原版 `0046C7F3` 恢复；
外部皮肤使用提供者布局与接入生命周期。详见 [重新排列恢复](WINDOW_REARRANGE_RECOVERY.md)。
原版音乐窗组件、历史在线服务等既有功能边界也不因菜单一致而自动补齐。

## 验证

本地测试代码保存在 `rebuild/tests/ui/shared_menu_tests.cpp`，仅在 `BUILD_TESTING=ON` 时构建，
不加入发行 ZIP，Actions 不执行测试。

- 从 5.7.9 资源创建实际 HMENU，对比主菜单和独立均衡器菜单的层级、标签、顺序、ID、启用及勾选。
- 覆盖关闭、自定义、推荐及 12 种类别；验证每次展开刷新勾选、不累积条目，自绘数据仍有效。
- 通过主窗口 `WM_COMMAND` 实际切换预设、禁用／恢复、自定义、推荐和环绕。
- 调用真实 WTL 均衡器弹出路径，确认初始化消息和完整类别列表。
- 对比五个播放模式及附加选项；验证主菜单的歌词显示／桌面／编辑分支、RichEdit 选区、媒体库与透明设置。

这些检查验证菜单与命令路由，不代表所有菜单涉及的网络、文件操作、不同皮肤及所有系统都已逐项端到端测试。

实测：宿主机共享菜单、均衡器、歌词菜单、桌面歌词菜单、全屏封面和项目链接六项相关测试通过；
歌词菜单测试补齐私有测试夹具的 ttpcomm 解压模块后通过，未修改生产皮肤加载逻辑。
最终的共享菜单回归在 XP SP3 和 Win7 SP1 上也均通过。
后续加入的“重新排列”测试同样在宿主机与两台虚拟机通过，详见其专项文档。

继续核对主菜单进入歌词编辑时，发现并修复隐藏歌词窗口未显示、激活目标错误及缺少全屏退出的问题。
详见 [主菜单编辑歌词核对](LYRIC_MAIN_MENU_EDIT_AUDIT.md)。
