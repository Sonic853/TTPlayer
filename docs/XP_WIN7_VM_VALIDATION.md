## 发现并修复：XP 播放列表行高

原版 `00425DEC` 使用 `SysListView32` 基类，`00482BAF` 创建目录和曲目两个
owner-data 控件；`0041CB83` 查询 `LVM_GETTOPINDEX` 和 `LVM_GETITEMRECT`。
重建版必须让原生滚动、键盘翻页与皮肤的行坐标一致。

以前用 `CreateFontW(-10, ..., L"Tahoma")` 假设原生行高总是 16 像素。
虚拟机实测 XP 为 13 像素，Win7 为 16 像素。XP 的原生翻页容量与皮肤绘制、
滚动范围因而可能不同。这是程序问题，不能用放宽测试断言解决。

`player_window_playlist_native.cpp` 改为使用正的字体单元高度，并在列表首次有数据时
读取实际行矩形，校准到 16 像素。仅调整供原生控件计算几何的字体；皮肤文字仍由
原来的绘制字体负责。空列表延后测量，不插入假曲目，每个控件只进行一次有界校准。

XP、Win7 均已通过原生行高、滚动、选择/焦点/锚点、目录翻页对照。
现代 Windows 的 WTL 行为、滚轮、框选、列表契约 4 项回归也通过。

## 发现并修复：Shell 解包的 COM 生命周期

`SkinPackage::ExtractTo(directory)` 的备用 Shell 路径中，`_variant_t content` 持有
`FolderItems` 的额外引用。旧代码先释放显式接口并调用 `CoUninitialize`，随后才析构该
VARIANT。XP 和 Win7 的 `skin-tt2012` 测试均出现 `0xC0000005`。

将 `CopyHere` 的参数放入独立作用域，使额外接口引用在 COM 关闭之前释放。
修复后，XP、Win7 及现代宿主的 TT2012、Vista、Vista 均衡器解包测试均通过。
播放器正常换肤仍使用传入 `ttpcomm` 的原版解压入口；两条路径不混淆。

## 测试环境修正

- 启动器使用 `CREATE_NO_WINDOW` 隐藏控制台，不再用 `STARTF_USESHOWWINDOW/SW_HIDE`
  覆盖被测界面的第一次显示。歌词/常规子页之前的可见性失败因此得到排除。
- 补齐原版皮肤、解包后的 `Skin.xml`、原版 EXE 图标以及 AddIn 依赖。
- 截取透明窗口时加入 `CAPTUREBLT`。XP/Win7 的普通屏幕 `BitBlt` 不包含这些
  layered 窗口，不能据此判断封面/歌词绘制错误。修正后，主窗口与预览提交位图
  在默认皮肤、LX-iPlay、TT2012 和 Vista 皮肤上的不透明像素对照为零差异。
- PNG 皮肤测试的父窗口改用普通自定义窗口类。旧系统的 `STATIC` 类带有
  `CS_PARENTDC`，无法用于该透明弹出窗口夹具；这不是播放器的实际窗口类。
- XP ComCtl32 v6 的 `TTM_GETTOOLINFO` 对 V1 查询会返回成功但不填充字段。
  使用 V2 查询后，可与 v5/v6 同时对照实际注册的 HWND、回调和动态文字。
- 路径测试按 Windows 的大小写及分隔符规则比较；不要求配置中的大小写字符串完全相同。
- XP 的转换测试不再强制要求不存在的 Media Foundation，改为执行原插件和原生 WAV 后备路径。
- XP 在 layered 窗口缩放后可能无法用 `GetLayeredWindowAttributes` 读回属性。
  独立 Win32 程序复现：查询返回 FALSE，但白色窗口叠加在黑底上的像素仍分别为
  `#000000`、`#323232`、`#ffffff`（alpha 0、50、255）。桌面歌词改用屏幕像素验证，
  实际读到 0 → 1 → 50 → 0 的悬停透明度序列，不因查询失败修改生产代码。
- XP owner-draw 菜单字符串查询的返回长度与终止字符串不一致，测试改为有界读取实际文字；
  空列表提示、曲目菜单重建、真实 `TrackPopupMenuEx`、4/12 控件鼠标悬停均通过。
- PNG 滚动条预期改为完整行数 `page_rows`；半行只参与绘制，不计入原生翻页容量。
- XP Luna 子页背景按系统主题绘制对照；本地 HTML 上传夹具先展开 8.3 路径，避免 IE
  导航后的长路径被测试的严格 URL 比较误判。

上述测试调整均保留在本地 `tests/`，不上传，也不加入 Actions。

## Win7 空间与防自动锁定

- `Win7_1.vdi` 是无快照的动态 VDI，原容量 10 GiB。
- 正常关机后增加 5120 MiB，得到 15 GiB；启动后使用 DiskPart 将相邻空间扩展到 C 盘。
- C 盘由 **10,128,191,488** 字节增至 **15,496,900,608** 字节，恰好增加 5 GiB。
  扩容后首次查询可用 **5,397,585,920** 字节，约 5.03 GiB。
- 清理对象限于本轮创建的测试副本和临时产物，没有手工删除 Windows 组件存储、
  Installer 或用户歌曲。清理前后容量由来宾系统查询。
- 最终清理阶段，Win7 可用空间从 **4,905,582,592** 增至 **5,385,928,704** 字节，
  回收约 **458 MiB**；此前另已移除旧文件属性测试目录。当前 C 盘约有 **5.02 GiB** 可用。
  XP 同步清除本轮临时文件；已删除两台机器上本轮创建的计划任务。
  保留当前兼容播放器及运行所需 DLL/皮肤，测试日志和源码在宿主本地 `tests/` 中归档。
- 关闭屏幕保护及交流供电下的自动熄屏、待机；Win7 另将自动休眠超时设为零。
  重启、用户重新登录后复核上述设置。用户账号和密码保留。

参考：[BitBlt 的 CAPTUREBLT 标志](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-bitblt)。
