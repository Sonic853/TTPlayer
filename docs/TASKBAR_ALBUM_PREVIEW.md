# 任务栏封面缩略图与主窗口 Peek

更新：2026-09-19。这是按用户要求添加的重建版功能。

## 行为

- 当前歌曲有可解码的内嵌封面时，任务栏缩略图等比显示完整封面，不添加外围黑边，保留图片透明度。
- 鼠标移到缩略图上触发的 Aero Peek 显示主窗口本身，包括皮肤和视觉效果子窗口。
- 暂停保留封面；无封面、封面损坏、停止或播放失败时取消自定义缩略图，由 Windows 显示主窗口。
- 原有上一首、播放／暂停、下一首缩略图按钮保留。迷你／全屏返回、Explorer 重建按钮、DWM 合成恢复时重新应用预览。

## 本次问题原因

之前将同一张封面同时用于 `WM_DWMSENDICONICTHUMBNAIL` 和
`WM_DWMSENDICONICLIVEPREVIEWBITMAP`。后者是桌面上主窗口位置的全尺寸预览，因此悬停后会看到
封面和黑色背景覆盖主窗口，看起来像主窗口被错误绘制。

此前为稳定预览尺寸而采用完整请求尺寸的黑色画布，使方形／竖向封面两边出现大块黑边。
微软规定缩略图消息中的宽高是**最大允许尺寸**，不要求填满整个矩形。现在根据每一次请求独立
计算封面尺寸：`200×120` 的上限下，2:1 封面输出 `200×100`，1:2 封面输出 `60×120`。
不裁切图片、不重复乘 DPI、不复用上一次缩放结果。

## 实现

`TaskbarPreview` 在 UI 线程管理封面和 DWM 属性。取得当前 reader 元数据后解码一次；
缩略图请求只缩放缓存，不再次读取媒体文件。封面最长边限制为 1024 像素。

图片复用公共 WIC／GDI+ 解码器及既有内嵌封面策略：reader 有 `ISoundThumbnail` 时使用第 0 张，
包括尊重空图片结果；无此接口时使用既有标签解析器。不把 Folder.jpg 或全屏备用背景当作歌曲封面。
提交缩略图使用 32 位预乘 BGRA，透明像素不再强制转为不透明黑色。

Peek 单独创建完整客户区大小的离屏位图，调用主窗口 `WM_PRINTCLIENT`，再按照 Z 序合成可见子窗口。
主窗口及 VisualCtrl 的打印路径复用正常绘制函数，不读取桌面截图、不向屏幕 DC 写入封面。
独立歌词／播放列表等顶层窗口仍由系统处理，不重复画进主窗口位图。

最小化时直接调用主窗口客户区绘制入口，避免 `DefWindowProc(WM_PRINT)` 改画程序图标；
同时保留子窗口布局、最小化前的客户区尺寸、偏移及窗口裁剪区域。Win7 会将最小化 HWND 的裁剪区域
替换为图标／标题区域，因此不能直接使用此时的 `GetWindowRgn` 裁剪 Peek。皮肤外部像素保持透明。
最大化后最小化继续使用已观察到的最大化尺寸；尚无真实尺寸时才通过正常窗口位置重建客户区。

封面之间直接替换缓存，不短暂关闭再开启自定义属性；无封面才恢复系统默认行为。
`WM_WINDOWPOSCHANGED`／`WM_SIZE` 检查尺寸、偏移、最小化状态、显示器和窗口形状的变化。
相同几何通知不重复使缓存失效。DWM 属性／提交失败时回退系统预览；超出离屏分配上限的 Peek
也回退，不把大窗口截成局部图片。

## 旧系统与接口合同

DWM 接口通过系统目录中的 dwmapi.dll 动态解析。Win7 开启桌面合成时支持；XP 或接口缺失、合成关闭时
保持系统原有行为，不引入新的高版本静态导入。

- [DwmSetIconicThumbnail](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmseticonicthumbnail)：最大尺寸、32 位位图、所有权。
- [DwmSetIconicLivePreviewBitmap](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmseticoniclivepreviewbitmap)：全尺寸 Peek、客户区范围及偏移。

## 本地验证

测试位于本地 `tests/`，不上传、不进入发行包，Actions 不运行测试。

- `taskbar_preview_tests`：封面比例、无外围填充、预乘透明度、窗口内容与封面分离、形状透明区、尺寸变化、
  最小化／最大化、换曲／停止／失败、合成与接口失败、GDI 对象释放。
- `skin_rebind_tests`：实际皮肤的 Peek 位图与屏幕像素比较，以及最小化后的皮肤和 VisualCtrl 内容。
- `taskbar_playback_tests`、`fullscreen_album_tests`：任务栏播放按钮与全屏封面回归。

真实 DWM 接口返回成功与 Explorer 鼠标悬停的视觉验证分别记录，前者不能替代后者。

### 2026-09-19 验证结果

- 普通 Release：预览、换肤、任务栏按钮、全屏封面 4 项回归通过。4 个实际皮肤的屏幕像素对比中，
  3 个完全一致，另一个差异为 89／174988 像素；最小化比较只排除随附属窗口隐藏而改变状态的 3 个按钮。
- 兼容 Release：预览回归通过；XP SP3、Win7 SP1 虚拟机运行同一兼容测试通过，包括 PNG 透明度和
  最小化尺寸／裁剪区域。静态导入审计通过：x86、子系统 5.01，19 个 DLL、649 项导入。
- 主机 Explorer 实际悬停截图确认主窗口保持皮肤画面；方形封面无外围黑边，竖图实际封面区域为
  61×122 像素，主窗口预览中检测到的红色测试封面像素为 0。
- 最小化后再次打开 Explorer 缩略图的鼠标自动化未能稳定枚举到预览窗口，未计为视觉测试通过。
  最小化路径已有位图内容／尺寸回归和 XP／Win7 测试，仍需区别于完整的 Shell 鼠标操作验证。
