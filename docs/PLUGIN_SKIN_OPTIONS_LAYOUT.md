# 皮肤页内层选项卡空白框修复

## 原因

`InitializeOptionsSkinTabs` 原来创建了高度为 20 个对话框单位的标准
`SysTabControl32`，却仅将其当作标题栏使用。标准选项卡还会绘制内容区边框，
因此在“原生／插件名称”下面留下一个空的浅框。

列表标题、列表和预览又按固定 22 个对话框单位下移，与实际标签高度脱节，
增加了留白。这是重建版新增插件选择器的布局问题。

## 修复

- 选项卡覆盖皮肤页，让列表、预览和元数据位于同一个完整内容区内。
- 设置字体、插入标签后，通过 `TabCtrl_AdjustRect` 获取实际内容区高度，
  据此移动上部控件；保留资源中的标题间距、列表底部和底部按钮位置。
- 将选项卡置于同级控件后方，配合 `WS_CLIPSIBLINGS`，防止标签在切换或获得
  焦点时覆盖列表、预览和文字。
- 无可用插件 DLL 时仍使用原资源布局。

## 验证

普通版和 XP／Win7 版 Release 构建通过；在当前 Windows 宿主上运行两版的
皮肤页专项检查：鼠标连续切换、方向键切换、外层页面返回、空列表、预览、
应用皮肤和关闭后重开均通过。两版无插件场景也通过原生布局检查。
实际窗口截图确认没有原先的空白条和浅框。

兼容版静态导入检查通过（19 个 DLL、648 个导入）。本次未在实际 XP／Win7
系统上运行。测试仅保存在本地 `tests/waskin/host_tests.cpp`，未加入 Actions。
