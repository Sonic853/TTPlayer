# DFX 吸附后无法继续拖动修复

日期：2026-09-28。

## 1. 原因与复现

导入 REG 后能正常创建 `DFX_WINDOW_11`（DFX 9 Winamp）窗口。此次故障位于宿主的窗口吸附适配，不在 REG 导入、授权信息或插件初始化路径。

修复前，`DspWindowProcedure` 将原生 `WM_MOVING` 提供的矩形直接交给播放器计算吸附。Win7 实测表明：窗口被修正到吸附边缘后，下一条消息可能只包含“当前已吸附位置 + 本次鼠标增量”。若鼠标每次移动 1 像素，且吸附距离为 10 像素，每条消息都会再次被修正回边缘，无法累积脱离距离。

真实 DFX 的修复前日志：

```text
窗口已吸附：left=350, top=200
向下累计移动 45 像素：每条消息的 top 仍为 201，吸附后回到 200
松开后：窗口位移 0，鼠标捕获为空
再次向右累计移动 35 像素：窗口位移仍为 0
```

这证实了慢速拖动被反复抵消；此次复现没有鼠标捕获未释放或线程死锁。

## 2. 原版与插件二进制依据

原版伪代码：`reverse/decompiled/TTPlayer.exe.pseudo.c`。

- `00427EDC / 00427E08 / 0043556C`：识别特殊 DSP 窗口并安装窗口过程；`0040BF67` 将窗口加入管理集合。原版识别的是旧类名 `DFX_WINDOW`、`Dee2`；本地插件实际使用 `DFX_WINDOW_11`。
- `0044F670 / 0046EAAC`：按下时保存窗口矩形、客户端抓取点和屏幕坐标。
- `0046EB64`：移动时使用当前鼠标位置相对保存的抓取点计算位移。窗口被吸附而暂时停止移动时，抓取点不会重置，后续鼠标移动仍然累积。
- `0044F804`：对候选矩形施加窗口／工作区吸附；`0046EB28` 结束拖动并释放捕获。

本地 `Dsp_Dfx.dll` 的窗口过程在 `1001EC65` 处理 `WM_NCHITTEST`，通过 `10033F80` 对可拖动区域返回标题栏命中；`1001EB17` 等分支调用 `DefWindowProcW`，进入系统移动流程。实际测试也确认标题区域返回 `HTCAPTION`。

重建版需要在插件的原生移动流程与播放器吸附算法之间保留累计位移。此次修复采用原版保留抓取基准的语义；没有将原版皮肤窗口的全部鼠标处理替换到第三方插件内部。

## 3. 修改

文件：`src/audio/winamp_dsp.cpp`。

1. `WM_ENTERSIZEMOVE` 为该窗口创建独立拖动状态。
2. 第一条 `WM_MOVING` 保存吸附前的候选矩形及当前屏幕鼠标坐标，保留系统启动标题栏拖动时已发生的位移。
3. 后续消息先按“首次候选位置 + 鼠标累计位移”还原未吸附位置，再交由播放器现有吸附逻辑处理。
4. `WM_EXITSIZEMOVE`、`WM_CANCELMODE`、`WM_NCDESTROY` 和宿主解除子类化时清理状态，避免影响下一次拖动。

插件的原窗口过程继续接收原有消息；吸附距离、吸附开关、主窗口带动已连接窗口的行为保持原有设置。修复未修改插件二进制、REG 内容及 `registry.json` 格式，也未增加系统运行库依赖。

## 4. 回归验证

使用本地真实 DFX DLL、已有文件注册表测试夹具和播放器实际 `PlayerWindow::HandleMessage`、`RegisteredDragWindows`、`BeginSkinBackgroundDrag`、`ContinueSkinBackgroundDrag` 路径。鼠标以每步 1 像素移动，测试同时保持 250 ms DSP 窗口发现定时器运行。

| --- | --- | --- |
| 主窗口底边吸附，慢速脱离，再次拖动 | 通过 | 通过 |
| 主窗口右边吸附，慢速水平脱离 | 通过 | 通过 |
| 播放列表窗口吸附与脱离 | 通过 | 通过 |
| 主窗口带动已吸附 DFX，随后单独拖走 DFX | 通过 | 通过 |
| Esc 取消并恢复原位置，随后重新拖动 | 通过 | 通过 |
| 关闭吸附后自由移动 | 通过 | 通过 |
| 屏幕工作区边缘慢速脱离 | 通过 | 通过 |
| 系统菜单移动的键盘操作 | 通过 | 通过 |
| 松开后鼠标捕获与拖动状态清理 | 通过 | 通过 |

修复后，Win7 初始复现用例中，向下移动 45 像素时窗口实际移动 45 像素，随后向右移动 35 像素时窗口实际移动 35 像素。两台虚拟机的完整回归均返回 0。本地 DSP 生命周期、配置窗口和消息转发回归也通过。

测试代码与日志仅在 `rebuild/tests`，未加入发行包；Actions 保持 `BUILD_TESTING=OFF`。本轮未在宿主桌面注入鼠标动作，也未逐一验证其他第三方 DSP 窗口。
