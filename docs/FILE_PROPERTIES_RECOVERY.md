# 文件属性窗口：原版对照与恢复

依据：`reverse/decompiled/TTPlayer.exe.pseudo.c`、原版 `TTPlayer.exe` 中的数据表，以及 `ttpres.dll` 的 DIALOG 224、225、372、374 和 TOOLBAR/BITMAP 149。

## 原有缺口

原重建窗口加载了属性和封面两个资源页，但高级模式只是只读列表；从文件名猜测标签、工具栏和字段编辑对话框没有命令处理。保存流程只识别七个基本字段，无法表达每首文件不同的编辑结果。MP3 写入器也只接受这七个字段。

这次恢复同时修改页面、编辑状态和实际标签写入，避免出现“界面可以编辑，但保存后没有变化”的情况。

## MP3 实际写入修复

- APEv2 的扩展文字字段可增加、修改、删除；保留未修改的扩展项和二进制项。
- ID3v2 的扩展字段写入 TXXX；替换和删除时移除原字段帧，避免旧值遮住新值。
- `AlbumArtist` 使用 TPE2，`Lyrics` 使用 USLT，同时读取对应旧版帧 TP2／ULT。
- 修复 UTF-16 读取按单字节裁掉结尾零的问题。此前 `Title` 的末尾英文字符、自定义字段名称末尾字符都可能丢失。
- 成功读取文件后以文件中的标签为准，删除标题、艺术家等字段后不再从播放列表旧缓存补回。
- 单曲与批量保存都使用原有隔离工作进程，保留超时、归档只读和只读属性确认。

## 验证与边界

本地测试位于 `rebuild/tests`，不提交测试子仓库，不加入 Actions。

已验证真实 MP3 文件往返读写、APEv2／ID3v2 自定义字段替换和删除、Unicode TXXX／USLT、批量混合值、字段添加弹窗、文件名猜测弹窗、基本／高级切换、直接单元格编辑、还原、重读、切歌自动保存、关闭不保存、PNG 批量写入与删除，并核对属性／高级／封面截图。

另通过原版读取插件验证 FLAC、APE、WMA 测试文件的标题、自定义 Unicode 字段及 PNG 封面写入，重新打开确认内容，并验证字段和封面删除后不再出现。

原有 `builtin_file_info_tests` 和 `file_info_probe_protocol_tests` 通过。普通版与 XP／Win7 版均构建验证；旧版静态导入兼容检查通过（19 个 DLL、655 个导入）。
