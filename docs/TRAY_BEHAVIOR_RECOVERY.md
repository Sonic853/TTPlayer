# 系统栏行为与最小化选项恢复（2026-09-25）

## 最终使用规则

位置：**千千选项 → 常规 → 选项 → 最小化到系统栏**。

| 选项 | 最小化按钮、任务栏最小化、右键菜单最小化 | 关闭按钮 | Alt+F4 / 右键菜单「退出」 |
| --- | --- | --- | --- |
| 无 | 普通最小化，保留任务栏按钮 | 退出 | 退出 |
| 点击最小化（默认） | 隐藏到系统栏，继续播放 | 退出 | 退出 |
| 点击关闭 | 普通最小化，保留任务栏按钮 | 隐藏到系统栏，继续播放 | 退出 |

配置为 `General/@MinimizeToTray`，取值依次为 `0/1/2`。按照用户最后的
要求，缺少字段的新旧配置都默认使用 `1`；明确保存的 `0` 仍然保留。
非法值回到默认 `1`。下拉框支持即时生效、保存和重置。

「在系统栏显示程序图标」继续控制常驻图标。即使关闭常驻图标，隐藏到
系统栏时仍临时显示图标，恢复窗口后移除临时图标。图标注册失败时不隐藏
窗口，避免程序继续播放却无法从任务栏或系统栏找回。

## 原版伪代码证据

来源：`reverse/decompiled/TTPlayer.exe.pseudo.c`。

### 图标注册和回调分发

- `0045FAD8` 调用 `00451A79(0x7E8, ...)`，安装托盘回调消息。
- `00451A79` 配置 `NIF_MESSAGE | NIF_ICON | NIF_TIP`。
- `00451AEA / 00451B0B / 00451B30` 分别添加、删除、控制显示图标。
- `004689AA` 将回调送入 `0046D2ED → 0046FE1E`；同时处理
  `TaskbarCreated`，在 Explorer 重启后重建图标。

### 鼠标行为：0046FE1E

| 消息 | 原版处理 |
| --- | --- |
| `WM_MOUSEMOVE` | 记录鼠标进入图标时应用是否激活 |
| `WM_LBUTTONDOWN` | 锁存按下状态，保留 Explorer 抢走焦点之前的激活状态 |
| `WM_LBUTTONUP` | 只有先收到按下才执行；已最小化则恢复，正常且原先激活则最小化，正常但未激活则置前 |
| `WM_RBUTTONUP` | 获取鼠标位置，设置菜单所有者为前台，转发 `WM_CONTEXTMENU`，最后投递 `WM_NULL` |
| 双击、中键、滚轮 | 没有专门动作；双击序列的第一次左键按下／松开已经执行一次 |

`004689AA` 在左键尚未松开时不覆盖激活记录，避免一次单击因 Explorer
自身获得焦点而被误判为“只置前”。这不是单纯的“双击恢复窗口”。

### 菜单与窗口命令

- 右键使用 `00460D88 → 0045DFBA` 的完整主菜单，共享动态子菜单和选中状态。
- `004685D7` 中 `0x7DD3` 是最小化命令，转发 `SC_MINIMIZE`。
- `0x7DD5` 则进入 `004A39EF`，在最小化和恢复之间切换。
- `004A39EF / 0046FE1E` 恢复隐藏的最小化窗口时，先显示窗口再恢复和置前。
- `0045CA57 → 00451B82` 在标题改变时更新系统栏悬停提示，而非只在创建图标时设置。

原版 `0046162B` 将最小化隐藏与 `TrayIcon` 等旧设置关联。这里按照用户
要求增加独立三选一设置；新的“点击关闭”及默认值是重建版扩展，不宣称是
原版已有选项。

## 重建版发现的问题及修复

1. **缺少单击状态机**：此前只有双击恢复。现在恢复原版按下／松开与激活
   锁存逻辑，避免一次双击执行两次相反操作。
2. **命令编号混用**：此前将 `32213 / 0x7DD5` 命名为最小化，且只执行
   最小化；真正 `32211 / 0x7DD3` 未在该入口处理。现在分别处理两个命令。
3. **回调参数处理不足**：此前直接要求 `wParam == 图标 ID`。当前保留
   XP 兼容的原版注册协议，同时兼容 version 4 的打包参数，避免把坐标
   误判为图标 ID。支持键盘激活、上下文菜单，并保留菜单结束后的 `WM_NULL`。
4. **右键分支不是完全缺失**：旧代码已有 `WM_RBUTTONUP` 转发。测试中，
   经典格式的回调在正常、最小化、隐藏窗口上均能绘制菜单，因此不能仅据
   用户症状断言旧分支从未工作，也不能断言所有故障都由 WTL 导致。本次
   补齐回调协议和完整事件链，并验证实际 Explorer 图标及对应菜单路径。
5. **提示文字未随曲目更新**：现在在未滚动标题变化时更新图标提示。
6. **收起与退出区分**：关闭按钮保留普通 `WM_CLOSE`；明确“退出”携带内部
   标记，直接执行原有保存、淡出与销毁流程。主窗口及其子控件的 Alt+F4
   在消息预处理阶段转入同一退出命令，避免被转换成普通关闭消息后收起到
   系统栏；选项等独立对话框仍保留各自的 Alt+F4 关闭行为。隐藏窗口不停止音频。
7. **覆盖任务栏和菜单最小化**：除 `SC_MINIMIZE`，还处理
   `WM_SIZE / SIZE_MINIMIZED`，覆盖任务栏或其它正常最小化入口。

## 验证

本地测试代码放在 `rebuild/tests/ui`，不加入发行包，也不修改 Actions 的
`BUILD_TESTING=OFF` 设置。

- 常规页：下拉框默认项、三项切换、XML 缺省／非法值／往返保存、分页
  切换与控件边界；包含语言选择器时已检查截图和文字位置。
- Windows 11 测试桌面：单击状态机、双击去重、命令路由、三种窗口状态
  的右键菜单绘制通过。该受限测试桌面不接受 Explorer 图标注册，因此
  不把这一环境记为真实托盘图标测试通过。
- VirtualBox Win7 / XP：Explorer 图标注册成功；窗口恢复、临时图标、
  最小化与关闭策略、Explorer 重建消息、右键菜单绘制及明确退出均验证。
- Windows 11 / Win7 / XP：在「点击关闭」模式下，经过实际消息预处理
  链的 Alt+F4 从主窗口或获得焦点的子控件均退出播放器；选项窗口的
  Alt+F4 只关闭选项窗口。关闭按钮收起及菜单退出的回归通过。
- 自动测试使用真实窗口／Explorer 图标，并发送相应窗口消息；没有宣称
  每个用例都通过物理鼠标完成。
- XP／Win7 发行版静态导入检查通过：19 个 DLL、656 个导入项。
