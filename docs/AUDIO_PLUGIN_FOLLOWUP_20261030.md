## 验收口径

每个系统运行以下程序组；CCE 内部断言另列，不与程序调用混算。

| 测试组 | 每系统程序／用例数 |
|---|---:|
| 保留的旧回归：ADIF、Profile、保存、边界、呈现时间轴、原始流定位、7350 | 1052 |
| 显式时钟与定位 | 65 |
| LD／LC960／Main7350 | 99 |
| 7350 LC960 | 2 |
| SSR 公共接口及配置／别名回归 | 55 |
| CCE 公共接口与边界程序 | 110 |
| 合计 | 1383 |

其中每系统 131 组为使用当前生产 `mp4.cpp` 重新编译的保存核心探针，1252 组直接加载最终 DLL；CCE 的 110 次调用包含 253 个边界断言场景，总计 359 个场景。本机另有完整 Main 逐字节截断 1131 项、SSR 核心 123 项、FFT／MDCT 数学 18 项，以及 CCE960 DRC 三项，均作为算法证据，不重复计入 1383。

每个实际宿主用例核对 DLL 完整路径、请求文件、播放时间推进、错误窗口及正常关闭。原版与重建版分别覆盖 16 种输入，包括新增 CCE、SSR 双声道／八声道 ADTS、LD480 低频／7350／预测、LC960 与显式 50000 Hz。它们不是实体音箱听音或所有音频设备验证。Win10 按此前约定由 Win11 代测，不声称实际运行了 Win10。

最终执行状态和对应文件哈希以私有 `rebuild/tests/plugins_followup_20261030/final-validation.json` 及本报告收尾记录为准，不能把早期候选 DLL 的通过日志用于发行文件。

## 明确保留的边界

本轮完成上面的核心缺口，不代表所有 AAC 扩展及其它插件的剩余边界已全部实现：

- CCE 与 SBR／PS、LTP、SSR 的组合仍明确拒绝；7350／14700 Hz SBR、表外核心时钟的 SBR、扩展 AOT 没有用近似解码冒充支持。
- LTP960 与 7350 LTP 的相关算法／合法配置已恢复，但仍缺独立真实有声码流验收。SSR960 则是标准要求拒绝的配置，不是待补功能。
- 不同解码器的 PNS 随机序列可造成波形差异。含 PNS 的官方 LD 向量保留逐帧覆盖及独立 FDK 对照；未将正常噪声差异误修成固定金样。
- 分片 MP4 保存仍要求现有空间足够；动态 ASC、多 sample description、DRM／在线 DASH 不属于已验收支持。ADIF VBR 时长估算、未知长度流不可随机定位的既有约束不变。
- MOD／VQF 的历史范围及 RM／XM 数值差异沿用此前报告；本轮没有借 AAC 通过结果宣布这些项目已解决。
