# 歌词窗口内容模式与编辑区域

## 行为

- 原生皮肤的歌词窗口右键菜单增加“显示内容”：歌词、视觉效果、歌词与视觉同屏。
- 歌词窗口单独保存视觉效果类型，不改变主窗口的视觉效果选择。
- 同屏模式复用 WSZ／WAL 的布局和绘制，支持全屏选项中的分区与叠加布局。
- 显示菜单中的“选项”移到最底部；原有文字、启用状态和命令保持不变。原生皮肤、WSZ 和 WAL 共用此处理。原歌词编辑菜单没有“选项”，不额外插入。
- 进入编辑时，工具栏与编辑器覆盖整个内容区，包括原先的视觉区域。编辑期间停止该区域的视觉绘制，防止残影；不修改此前的内容模式和效果，退出编辑后恢复显示。
- 编辑中切换显示内容不会隐藏编辑器或清空未保存的文本。主窗口、歌词窗口和皮肤标题区不参与编辑区域扩展。

## 实现

`player_window_lyric_content.cpp` 管理原生内容菜单、状态和双缓冲绘制；
`player_window_skin_plugin.cpp` 复用内容菜单、命令路由及歌词区域命中规则；
`player_window_lyrics.cpp` 将编辑器布局扩展至完整内容矩形；
`player_window_visual.cpp` 将视觉工作线程的刷新目标指向实际内容窗口。

原生窗口包含视觉时暂时不使用歌词背景色键，防止频谱背景被挖空。切回纯歌词后恢复原透明设置。
全屏、桌面歌词和换肤返回均保留原生窗口的内容偏好。

主配置 `Lyric` 节新增：

| 属性 | 默认值 | 含义 |
| --- | --- | --- |
| `WindowContentMode` | `1` | `1` 歌词、`2` 视觉、`3` 同屏 |
| `WindowVisualType` | `1` | `0` 无效果，其余 `1..6` 与现有视觉效果编号一致 |

WSZ／WAL 继续由插件保存各自模式，无 SDK／DLL ABI 变更，本次更新主程序即可。

## 本地验证

测试保留在 `tests/waskin`，不进入发布包，不接入 Actions。

- `--native-content-only`：原生与 WSZ 的菜单、三种模式、七种效果、真实 FFT 绘制、区域拖动、透明恢复、全屏／桌面往返、编辑覆盖、配置保存与换肤。
- 加 `--modern-only`：同一组检查使用 WAL／HeadAMP 内容窗口。
- `--video-only` 与 `--modern-content-only`：既有 WSZ／WAL 的输入、菜单、字体、绘制和编辑器回归。

XP 窗口缩放后的 `GetLayeredWindowAttributes` 查询可能失败；该分支使用带 `CAPTUREBLT` 的屏幕像素验证实际色键效果，不将查询失败当作绘制失败。
