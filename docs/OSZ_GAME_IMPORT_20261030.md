# 播放列表 OSZ 副本导入（2026-10-30）

OSZ 音频条目的右键菜单新增“导入到 osu!”和“导入到 osu!lazer”。只有可选 `AddIn/ttp_osu.dll` 提供导入接口且对应配置路径通过游戏识别时才显示；普通音频或混合选择不显示。多选同一 OSZ 的歌曲去重为一次导入。

确认弹窗默认勾选“保留 osz 文件”。所有模式都复制完整 OSZ 并核对 SHA-256，只把副本交给明确选择的游戏。进度可取消；已经提交后停止等待不会关闭游戏。游戏启动或删掉副本都不直接记为导入成功，需要核对曲库索引与全包资源。

当前入口的原包仍被播放列表引用，因此取消保留时也会保护原件，并在结果提示中解释，避免歌曲和背景失效。本次不自动迁移播放列表引用。无法确认时保留原件及 Local AppData/TTPlayer/OsuImports 下的任务，重复操作继续核验。

解析、投递和核验位于独立 `ttp_osu` 的 `import.h` ABI 1（序号 7）。播放器负责菜单、确认、进度、通用只读压缩包 I/O 和对应歌曲列表强制刷新。旧版 DLL 的已有功能不受影响。Action 下载和打包审计已接受并校验新增的可选导出。

构建输出：`build/Release/TTPlayer.exe`、`TTPlayerRebuild.exe`、`AddIn/ttp_osu.dll`，文件版本 2026.10.30。测试证据位于私有 `tests/osu_import_20261030/`：18 项自动导入场景、Windows 11 隔离播放器的默认保留确认及完成结果、旧／新版 DLL 与错误导出的两套打包审计。EXE 与 DLL 通过 XP／Win7 静态导入检查。

本次提交流程使用模拟游戏，另只读核对了本机真实 stable／lazer 索引；没有执行真实游戏端到端新包导入或 XP／Win7 虚拟机运行。副本使用 Local AppData，跨卷实际投递待测。源包在游戏实际扫描／存储树中时拒绝导入；pending 任务尚无强制重投入口。

完整算法、保留规则和边界记录在独立 `ttp_osu/docs/OSZ_IMPORT_IMPLEMENTATION_20261030.md`。
