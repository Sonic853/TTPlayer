# OSZ 谱面包音频与背景封面支持

日期：2026-10-16。已根据第二个样本扩展为按谱面引用导入多音频，替代初版“一包一首”的限制。

2026-10-25 更新：OSZ 解析已迁入独立 `ttp_osu.dll`，以下格式行为保持不变。当前接口、构建和测试见 [OSZ 插件迁移](OSZ_PLUGIN_MIGRATION_20261025.md)；第 6、7 节保留迁移前的历史验证和发行记录。

## 1. 格式与样本分析

官方将 [`.osz` 定义为 ZIP 格式的谱面包](https://osu.ppy.sh/wiki/en/Client/File_formats/osz_(file_format))，其中可以包含多个难度的 `.osu`、音乐、击打音效、皮肤图片和视频。**`.osz` 是有效后缀，不应提示改名为 `.zip`。**

[`.osu` 官方格式](https://osu.ppy.sh/wiki/en/Client/File_formats/osu_(file_format))使用 UTF-8 文本。`[General]` 的 `AudioFilename` 指向音乐；`[Events]` 的背景事件 `0,0,"图片路径",x,y` 指向背景。路径相对于该 `.osu` 所在目录。视频事件和击打音效不是音乐或专辑封面。

用户样本：`C:\Users\Sonic853\Downloads\44443 Bilibili Douga - Night of Feifan Brother.osz`。

| 项目 | 实际内容 |
| --- | --- |
| 文件大小 | 14,846,197 字节 |
| SHA256 | `7a679c79334be3db3fccb10d51a8154091cd29e99c47c5bedf96edcc0a806341` |
| ZIP 成员 | 22 个，Deflate 压缩 |
| 谱面 | 6 个 `.osu`，格式版本 v10 |
| 音乐引用 | 全部为 `Night of Feifan Brother.mp3`，3,454,594 字节 |
| 背景引用 | 全部为 `bg.jpg`，24,240 字节 |
| 其他内容 | WAV 击打音效、皮肤 PNG、`video.flv` |

按照普通 ZIP 的“所有可播放成员”规则，会误导入击打音效。因此 OSZ 在导入阶段单独解析谱面，底层继续使用已有只读 ZIP 流和解码器。

## 2. 导入规则

1. 打开文件筛选器加入 `*.osz`；拖放、命令行、添加文件及文件夹扫描复用同一导入流程。
2. 按包内成员顺序读取所有 `.osu`，收集其中能够解析且实际存在的 `AudioFilename` 引用。
3. 每个不同的音频成员生成一个 `外层.osz|音乐成员` 条目，按首次被谱面引用的顺序排列。多个难度引用同一文件只导入一次；大小写、斜杠、`.` 和合法 `..` 别名解析后去重，不同目录下的同名文件分别保留。不会按音频文件内容哈希合并不同成员。
4. 无效谱面和不存在的引用会被跳过，保留其他有效引用；整个包没有有效音频引用时报告导入错误。不回退到包内任意音频，也不猜测最大的文件。无法解码的被引用文件交给正常播放错误流程处理。
5. 保留现有同批次去重、信息延迟加载、后台导入进度和取消机制。普通 ZIP／RAR 的音频和 CUE 枚举规则不变。

`AudioLeadIn`、`PreviewTime` 和谱面时间轴不用于裁切音乐：播放器播放引用音频本身的完整时长，不模拟 osu! 的游戏预览或击打音效。

## 3. 封面优先级

顺序为 **音频内嵌封面 → 该音频对应谱面的背景 → 无封面**。

- 复用播放源和文件属性读取进程已有的封面入口；只有音频没有封面时才解析 OSZ 背景。播放列表批量信息进程保留原有不返回封面的轻量策略，避免每首歌加载图片。
- 每首音频分别保留首次找到的、实际存在的背景引用。若第一个有效难度没有背景，继续查看引用同一首音频的其他难度；不会借用引用其他音频的谱面背景。播放时的定向查询只匹配当前音频，找到其背景即可返回。
- 识别数字背景事件 `0` 和命名事件 `Background`；支持带引号、含逗号的文件名。忽略 `Video`／数字 `1`、Storyboard、皮肤图及击打样本。
- 背景只接受现有图像链支持的 PNG、JPEG、BMP、GIF 文件头。不存在或无效的背景不会阻止音频播放。
- OSZ 不使用普通压缩包的 `cover.*`／`folder.*` 猜测规则，避免将谱面包内的无关皮肤图当成专辑封面。

## 4. 路径、边界与只读

- 支持 UTF-8、BOM、CRLF／LF、Unicode 文件名、斜杠／反斜杠、相对目录和包内合法 `..`。
- 路径比较不区分大小写，匹配后保留实际成员名称与顺序；拒绝越过包根目录、盘符、绝对路径、URL 和非法路径字符。
- 每个谱面最多 16 MiB，每次解析最多检查 256 个谱面、处理 64 MiB 谱面文本。超过上限时报告大小限制，本包不提交部分曲目，避免静默遗漏后续谱面的音乐。读取过程继续使用压缩包 CRC、解压限制、密码交互和取消回调；取消会丢弃本批新增结果。
- 导入只读谱面和目录，音乐仍由成员流读取，不把整个包展开到用户目录。
- 归档标签与封面继续只读，不提供标签、歌词、增益或封面写回。
- 后缀纠正明确接受 ZIP 容器的 `.osz`／`.OSZ`，在外层文件和逻辑成员播放时均不建议改为 ZIP。普通错误后缀压缩包仍保留已有提示规则。

## 5. 实现位置

| 位置 | 职责 |
| --- | --- |
| 独立项目 `ttp_osu/src/plugin.cpp`、`parser.cpp` | OSZ 包内枚举、引用解析、按首次引用顺序收集音频、成员去重与各自的背景匹配 |
| `include/ttplayer/audio/osz_archive.h`、`src/audio/osu_plugin_client.cpp` | 动态加载 OSZ 插件、通用只读 I/O 回调和宿主结果转换 |

| `src/audio/archive_member.cpp` | OSZ 路径识别与谱面背景读取 |
| `src/audio/extension_correction.cpp` | 接受 OSZ 后缀，避免改名为 ZIP |

现有重建 `ttpcomm.dll` 按 ZIP 文件头提供只读成员访问。2026-10-25 起新增 OSU ABI 1，由独立插件负责 OSZ 解析，音频继续复用已有解码器。这是重建版的新格式扩展，不代表原版播放器已经支持 OSZ 谱面筛选。

## 6. 验证

本地私有测试位于 `tests/archive_support/osz_20261016/`，通过默认关闭的 `TTPLAYER_BUILD_OSZ_TESTS` 构建；不上传测试源码、样本，不加入 Action 测试或发行包。

验证项目包括：首个真实样本仍只导入一首，第二个真实样本准确导入三首；多难度去重、音效和视频排除；相对目录与 Unicode；同名不同目录和路径别名；每首音乐各自匹配背景；缺失引用与非法路径；已找到第一首后取消或超过数量限制不能提交部分列表；后缀保护；真实 PCM 解码与中间定位；播放源和文件属性进程封面一致；列表信息进程维持轻量只读；同包部分音频内嵌 APIC、部分音频使用背景；无背景正常播放；普通 ZIP／RAR CUE 回归；读取后两个用户归档内容不变。
